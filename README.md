### 📅 Календарь звонков — сервис бронирования на Django

Учебный сервис, в котором гость выбирает время звонка, а владелец
календаря настраивает типы встреч. Реализовала JSON API на Django
и описала контракт в TypeSpec. Из OpenAPI-спецификации
генерируется TypeScript-клиент для фронтенда.

Добавила сквозные тесты Playwright для бронирования, проверки
конфликта слотов и создания типа встречи. Настроила запуск через
Docker Compose и проверки в GitHub Actions.
